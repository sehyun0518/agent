# Hook — 자동 출처 문구 금지

- 이벤트: `before-capability`
- blocking: 예.

## 검사

커밋 메시지와 PR 본문에 자동화 도구 관련 출처 문구(생성 도구 이름, co-author 라인,
서명 배지 등)가 **자동으로** 들어갔는지 본다.

저장소 profile의 `git.automaticAttribution` 값에 따라 판정한다.

| 값 | 동작 |
|---|---|
| `forbidden` (기본) | 출처 문구가 있으면 차단 |
| `allowed` | 통과 |

## 왜 기본이 금지인가

커밋 이력과 PR은 **사람이 남기는 기록**이다. 도구가 자기 이름을 자동으로 끼워 넣으면
저장소마다 다른 정책과 충돌하고, 한번 들어간 이력은 되돌리기 번거롭다.

사용자가 명시적으로 요청하면 넣는다. 기본값이 "안 넣음"이라는 뜻이지 "절대 못 넣음"이
아니다.

## 차단 시

`policy-denied`로 분류하고 halt한다. 어떤 문구가 문제인지 보여주고, 그 문구를 뺀
메시지로 다시 호출하도록 안내한다.
