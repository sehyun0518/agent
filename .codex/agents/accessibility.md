# Accessibility Role for Codex

원본 역할 정의는 `agents/accessibility.md`다.

## 사용

1. `agents/accessibility.md`를 읽고 따른다.
2. 병합된 통합 빌드 위에서 키보드, 포커스, 시맨틱, 대비, 모션 환경설정을 점검한다.
3. 접근성 범위의 수정만 직접 수행한다.
4. 토큰 자체가 문제인 대비 결함은 `design` 역할로 되돌린다.
